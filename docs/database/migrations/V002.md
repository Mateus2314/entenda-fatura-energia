## Summary

Creates `clients` table with:
- 9 columns
- 1 primary key (user_id)
- 1 foreign key to users
- 1 unique constraint (cpf)
- 2 check constraints (cpf format, state format)
- 3 performance indexes
- Full documentation comments

---

## Key Fields

- **user_id** (UUID, PK, FK) - Links to users table
- **address** (VARCHAR) - Street address
- **city** (VARCHAR) - City name
- **state** (VARCHAR) - State abbreviation (UF)
- **zip_code** (VARCHAR) - ZIP code (8 digits)
- **cpf** (VARCHAR, UNIQUE) - Brazilian individual tax ID (11 digits)
- **registration_date** (DATE) - Registration date (defaults to today)
- **created_at, updated_at** (TIMESTAMP) - Audit timestamps
