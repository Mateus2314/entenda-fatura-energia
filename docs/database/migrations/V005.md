## 🎯 What It Does

Creates the `tariffs` table to store:
- **Energy tariffs** from ANEEL API (Resource: fcf2906c-7c32-4b9b-a637-054e7a5234f4)
- **Tariff flags** (bandeiras tarifárias) from ANEEL API (Resource: 0591b8f6-fe54-437b-b72b-1aa2efd46e42)

This table supports the integration with ANEEL Open Data API to fetch and store Brazilian energy tariff information.

---

## 📊 Key Fields

### Primary Key
- `id` (UUID) - Auto-generated

### Energy Tariffs Fields (from ANEEL API)
- `generation_date` (DATE) - Dataset generation date
- `distributor` (VARCHAR) - Energy distributor name (e.g., "CPFL JAGUARI")
- `cnpj_distributor` (VARCHAR) - Distributor CNPJ (14 digits)
- `valid_from` / `valid_until` (DATE) - Tariff validity period
- `subgroup` (VARCHAR) - Consumer subgroup (A2, B1, etc.)
- `tariff_modality` (VARCHAR) - Azul, Verde, Convencional
- `consumer_class` / `consumer_subclass` (VARCHAR) - Consumer classification
- `tariff_post_name` (VARCHAR) - Ponta, Fora ponta
- `tusd_value` (DECIMAL) - Distribution tariff value
- `te_value` (DECIMAL) - Energy tariff value

### Tariff Flags Fields (from ANEEL API)
- `competence_date` (DATE) - Flag validity month
- `activated_flag_name` (VARCHAR) - Flag color (Verde, Amarela, Vermelha P1/P2)
- `flag_additional_value` (DECIMAL) - Additional cost per 100 kWh

### Audit Fields
- `created_at` / `updated_at` (TIMESTAMP) - Auto-managed

---

## 🔒 Constraints

1. **Primary Key:** `id` (UUID)
2. **Check:** Valid date range (`valid_until >= valid_from` or NULL)
3. **Check:** CNPJ format validation (14 digits)
4. **Check:** Non-negative values for `tusd_value`, `te_value`, `flag_additional_value`

## 📇 Indexes

5 performance-optimized indexes:

- `idx_tariff_distributor` - Filter by distributor
- `idx_tariff_competence_date` - Flag matching by month

## 🧪 Common Queries

### Find Active Tariff
```sql
SELECT * FROM tariffs
WHERE 
    distributor = 'CPFL JAGUARI'
    AND subgroup = 'B1'
    AND tariff_modality = 'Convencional'
    AND valid_from <= CURRENT_DATE
    AND (valid_until IS NULL OR valid_until >= CURRENT_DATE)
ORDER BY valid_from DESC
LIMIT 1;
```

### Get Current Flag
```sql
SELECT activated_flag_name, flag_additional_value
FROM tariffs
WHERE 
    competence_date = DATE_TRUNC('month', CURRENT_DATE)
    AND activated_flag_name IS NOT NULL
ORDER BY flag_generation_date DESC
LIMIT 1;
```

### Calculate Total Cost (with flag)
```sql
SELECT 
    (150 * (tusd_value + te_value)) AS base_cost,
    ((150 / 100.0) * flag_additional_value) AS flag_cost,
    (150 * (tusd_value + te_value)) + ((150 / 100.0) * flag_additional_value) AS total_cost
FROM tariffs
WHERE distributor = 'CEMIG'
    AND valid_from <= CURRENT_DATE
    AND (valid_until IS NULL OR valid_until >= CURRENT_DATE)
LIMIT 1;
```
