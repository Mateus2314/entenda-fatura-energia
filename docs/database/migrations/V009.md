## 🎯 What It Does

Creates the `consultant_clients` join table to manage:
- Many-to-Many relationships between consultants and clients
- Consultant assignment tracking
- Relationship status management (ACTIVE/INACTIVE/PENDING)
- Access control foundation

**Relationship:** Many-to-Many (Consultant ↔ Client)

---

## 📊 Key Fields

### Composite Primary Key
- `consultant_id` (UUID) + `client_id` (UUID)

### Association Data
- `assigned_at` (TIMESTAMP) - When relationship was created
- `status` (VARCHAR) - ACTIVE, INACTIVE, or PENDING

---

## 🔒 Constraints

1. **Composite Primary Key:**
   - (consultant_id, client_id) - Prevents duplicates

2. **Foreign Keys (2):**

3. **Check Constraint:**

## 🧪 Common Queries

### Assign Consultant to Client
```sql
INSERT INTO consultant_clients (consultant_id, client_id, status)
VALUES ('consultant-uuid', 'client-uuid', 'ACTIVE');
```

### Get All Clients of Consultant
```sql
SELECT cc.*, u.name AS client_name
FROM consultant_clients cc
JOIN clients c ON cc.client_id = c.user_id
JOIN users u ON c.user_id = u.id
WHERE cc.consultant_id = 'consultant-uuid'
  AND cc.status = 'ACTIVE';
```

### Get All Consultants of Client
```sql
SELECT cc.*, u.name AS consultant_name
FROM consultant_clients cc
JOIN consultants cons ON cc.consultant_id = cons.user_id
JOIN users u ON cons.user_id = u.id
WHERE cc.client_id = 'client-uuid';
```

### Check Access
```sql
SELECT EXISTS(
    SELECT 1 FROM consultant_clients
    WHERE consultant_id = ? AND client_id = ?
      AND status = 'ACTIVE'
) AS has_access;
```

### Count Active Clients
```sql
SELECT consultant_id, COUNT(*) AS active_clients
FROM consultant_clients
WHERE status = 'ACTIVE'
GROUP BY consultant_id;
```

## 💡 Business Rules

### Many-to-Many Relationship
- One consultant → many clients
- One client → many consultants (over time)
- Composite PK prevents duplicates

### Status Management
- **ACTIVE**: Current relationship, grants access
- **INACTIVE**: Past relationship, no access
- **PENDING**: Invitation sent, awaiting approval

### Access Control
- Consultant can only view bills of ACTIVE clients
- Security layer for data protection
- Audit trail of relationships

### Cascade Delete
- Delete consultant → Remove all associations
- Delete client → Remove all associations
- Maintains referential integrity
