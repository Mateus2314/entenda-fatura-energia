## Summary

Creates `consultants` table with:
- 11 columns
- 1 primary key (user_id)
- 1 foreign key to users
- 1 unique constraint (cnpj)
- 3 check constraints (cnpj, state, zip_code formats)
- 3 performance indexes
- Full documentation comments

---

## Key Fields

- **user_id** (UUID, PK, FK) - Links to users table
- **consultant_name** (VARCHAR) - Consultant's full name
- **company** (VARCHAR) - Company name
- **cnpj** (VARCHAR, UNIQUE) - Brazilian company tax ID (14 digits)
- **address, city, state, zip_code** - Complete address
- **registration_number** - Professional license (optional)
- **company_logo** - Company branding (optional)
- **registration_date** - Registration date (defaults to today)

---

## Consultant vs Client

| | Client | Consultant |
|---|--------|------------|
| Tax ID | CPF (11 digits) | CNPJ (14 digits) |
| Type | Individual (PF) | Company (PJ) |
| Company Info | ❌ | ✅ |
| Logo | ❌ | ✅ |
