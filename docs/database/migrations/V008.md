## 🎯 What It Does

Creates the `analyses` table to store:
- Calculated metrics from electricity bills
- Historical consumption averages
- Cost per kWh calculations
- Month-over-month comparisons
- Savings recommendations
- Generated PDF reports

**Relationship:** One-to-One with electricity_bills

---

## 📊 Key Fields

### Primary Key
- `id` (UUID) - Auto-generated

### Foreign Key
- `bill_id` (UUID) - Parent bill (required, UNIQUE, CASCADE DELETE)

### Calculated Metrics
- `average_consumption` (DECIMAL) - Historical average kWh
- `cost_per_kwh` (DECIMAL) - Calculated cost per kilowatt-hour
- `comparison_prev_month` (DECIMAL) - % change from previous month

### Recommendations
- `savings_tips` (TEXT) - JSON or text recommendations
- `report_pdf_url` (TEXT) - Path to generated PDF report

### Audit
- `created_at` (TIMESTAMP) - Creation timestamp
- **NO `updated_at`** - Immutable snapshots

---

## 🔒 Constraints

1. **Foreign Key:**
   - Bill (required, UNIQUE, CASCADE DELETE)

2. **Check Constraints (2):**
   - Non-negative `average_consumption`
   - Non-negative `cost_per_kwh`

3. **One-to-One Enforcement:**
   - UNIQUE constraint on `bill_id`

## 🧪 Common Queries

### Get Analysis for Bill
```sql
SELECT * FROM analyses
WHERE bill_id = 'bill-uuid';
```

### Check if Bill has Analysis
```sql
SELECT EXISTS(
    SELECT 1 FROM analyses WHERE bill_id = 'bill-uuid'
) AS has_analysis;
```

### Get Bills Without Analysis
```sql
SELECT eb.*
FROM electricity_bills eb
LEFT JOIN analyses a ON eb.id = a.bill_id
WHERE a.id IS NULL;
```

### Find High Cost Analyses
```sql
SELECT * FROM analyses
WHERE cost_per_kwh > 0.85
ORDER BY cost_per_kwh DESC;
```

### Find High Consumption Increases
```sql
SELECT * FROM analyses
WHERE comparison_prev_month > 25
ORDER BY comparison_prev_month DESC;
```

## 💡 Business Rules

### One-to-One Relationship
- Each bill has **zero or one** analysis
- Analysis is optional
- UNIQUE constraint enforces relationship

### Immutable Snapshots
- No `updated_at` field
- Analyses represent point-in-time calculations
- To update: delete and recreate

### Calculated Fields
- **average_consumption**: Historical avg (last 3-6 months)
- **cost_per_kwh**: total_amount ÷ consumption_kwh
- **comparison_prev_month**: ((current - previous) / previous) × 100

### Optional Fields
- All metric fields can be NULL
- Service layer calculates before INSERT

## 📖 Analysis Calculation Example

```java
// 1. Calculate average consumption
BigDecimal avgConsumption = recentBills.stream()
    .map(ElectricityBill::getConsumptionKwh)
    .reduce(BigDecimal.ZERO, BigDecimal::add)
    .divide(new BigDecimal(recentBills.size()), 2, RoundingMode.HALF_UP);

// 2. Calculate cost per kWh
BigDecimal costPerKwh = bill.getTotalAmount()
    .divide(bill.getConsumptionKwh(), 4, RoundingMode.HALF_UP);

// 3. Calculate comparison
BigDecimal comparison = currentConsumption
    .subtract(previousConsumption)
    .divide(previousConsumption, 2, RoundingMode.HALF_UP)
    .multiply(new BigDecimal(100));

// 4. Generate tips
if (comparison.compareTo(new BigDecimal(20)) > 0) {
    tips.append("Consumo muito alto. Verifique equipamentos.");
}
```
