## 🎯 What It Does

Creates the `electricity_bills` table to store:
- Energy consumption invoices
- Billing data (amount, consumption, dates)
- Relationships to clients, consultants, and tariffs
- PDF storage references
- Installation and invoice numbers

---

## 📊 Key Fields

### Primary Key
- `id` (UUID) - Auto-generated

### Foreign Keys (Relationships)
- `client_id` (UUID) - Bill owner (required, CASCADE DELETE)
- `consultant_id` (UUID) - Assigned consultant (optional, SET NULL)
- `tariff_id` (UUID) - Applied tariff (required, RESTRICT)

### Bill Data
- `reference_month` (DATE) - Billing month (YYYY-MM-01)
- `due_date` (DATE) - Payment deadline
- `total_amount` (DECIMAL) - Total bill amount
- `consumption_kwh` (DECIMAL) - Energy consumption

### Additional Info
- `pdf_url` (TEXT) - Path to bill PDF
- `installation_number` (VARCHAR) - UC number
- `invoice_number` (VARCHAR) - Bill number

### Audit Fields
- `created_at` / `updated_at` (TIMESTAMP) - Auto-managed

---

## 🔒 Constraints

1. **Foreign Keys (3):**
   - Client (required, CASCADE)
   - Consultant (optional, SET NULL)
   - Tariff (required, RESTRICT)

2. **Check Constraints (3):**
   - `due_date > reference_month`
   - `total_amount >= 0`
   - `consumption_kwh >= 0`

## 🧪 Common Queries

### Get Client's Bills
```sql
SELECT * FROM electricity_bills
WHERE client_id = 'client-uuid'
ORDER BY reference_month DESC;
```

### Calculate Cost per kWh
```sql
SELECT 
    id,
    total_amount / NULLIF(consumption_kwh, 0) AS cost_per_kwh
FROM electricity_bills
WHERE consumption_kwh > 0;
```

### Find Overdue Bills
```sql
SELECT * FROM electricity_bills
WHERE due_date < CURRENT_DATE
ORDER BY due_date ASC;
```

### Monthly Consumption Comparison
```sql
SELECT 
    reference_month,
    consumption_kwh,
    LAG(consumption_kwh) OVER (ORDER BY reference_month) AS prev_month,
    consumption_kwh - LAG(consumption_kwh) OVER (ORDER BY reference_month) AS diff
FROM electricity_bills
WHERE client_id = 'client-uuid'
ORDER BY reference_month;
```

## 💡 Business Rules

### Client Relationship
- Every bill belongs to ONE client
- Client deletion removes all their bills (CASCADE)

### Consultant Assignment
- Bills can exist without consultant
- Consultant deletion keeps bills but sets consultant_id to NULL

### Tariff Application
- Every bill uses ONE tariff
- Cannot delete tariff if bills are using it (RESTRICT)

### Date Validation
- Due date must be AFTER reference month
- Reference month stored as first day (YYYY-MM-01)

### Non-Negative Values
- Amount and consumption must be >= 0
- Zero consumption allowed (minimum charges)
