## 🎯 What It Does

Creates the `bill_items` table to store:
- Individual line items for each electricity bill
- Consumption charges (peak/off-peak/standard)
- Demand charges
- Tariff flag charges
- Taxes and fees
- Other charges

**Relationship:** Many-to-One with electricity_bills

---

## 📊 Key Fields

### Primary Key
- `id` (UUID) - Auto-generated

### Foreign Key
- `bill_id` (UUID) - Parent bill (required, CASCADE DELETE)

### Item Data
- `item_type` (VARCHAR) - Type from 8 valid values
- `description` (VARCHAR 500) - Item description
- `quantity` (DECIMAL) - Quantity (optional, e.g., kWh)
- `unit_price` (DECIMAL) - Price per unit (optional)
- `amount` (DECIMAL) - Total amount (required)

### Audit Fields
- `created_at` / `updated_at` (TIMESTAMP) - Auto-managed

---

## 🏷️ Item Types (8 Valid Values)

1. **CONSUMPTION_PEAK** - Peak hours consumption
2. **CONSUMPTION_OFF_PEAK** - Off-peak hours consumption
3. **CONSUMPTION_STANDARD** - Standard hours consumption
4. **DEMAND** - Demand charge
5. **TARIFF_FLAG** - Tariff flag surcharge
6. **PUBLIC_LIGHTING** - Public lighting tax (CIP)
7. **TAXES** - ICMS, PIS, COFINS
8. **OTHER** - Administrative fees, adjustments

---

## 🔒 Constraints

1. **Foreign Key:**
   - Bill (required, CASCADE DELETE)

2. **Check Constraints (4):**
   - Non-negative `quantity`
   - Non-negative `unit_price`
   - Non-negative `amount`
   - Valid `item_type` (8 values)

## 🧪 Common Queries

### Get All Items for a Bill
```sql
SELECT * FROM bill_items
WHERE bill_id = 'bill-uuid'
ORDER BY item_type;
```

### Calculate Bill Total
```sql
SELECT 
    bill_id,
    SUM(amount) AS total
FROM bill_items
WHERE bill_id = 'bill-uuid'
GROUP BY bill_id;
```

### Get Consumption Items Only
```sql
SELECT * FROM bill_items
WHERE 
    bill_id = 'bill-uuid'
    AND item_type LIKE 'CONSUMPTION_%'
ORDER BY item_type;
```

### Compare Peak vs Off-Peak
```sql
SELECT 
    SUM(CASE WHEN item_type = 'CONSUMPTION_PEAK' THEN quantity ELSE 0 END) AS peak_kwh,
    SUM(CASE WHEN item_type = 'CONSUMPTION_OFF_PEAK' THEN quantity ELSE 0 END) AS offpeak_kwh
FROM bill_items
WHERE bill_id = 'bill-uuid';
```

## 💡 Business Rules

### Many-to-One Relationship
- Each bill has **multiple items** (typically 5-15)
- Each item belongs to **ONE bill**

### Cascade Delete
- Deleting bill removes all its items
- Maintains referential integrity

### Item Types
- Only 8 predefined types allowed
- Enforced by check constraint

### Optional Fields
- `quantity` and `unit_price` can be NULL
- Useful for taxes and fees without per-unit pricing

### Calculations
- `quantity` × `unit_price` should ≈ `amount`
- Service layer handles calculation
