# \# Project Requirements

# 

# \## ✅ Functional Requirements

# 1\. The system must allow users to input bill data (consumption, total amount, distributor, tariff flag, month/year).

# 2\. The system must query the ANEEL API for tariffs and flags.

# 3\. The system must validate the user-provided values.

# 4\. The system must generate a PDF report with summary and energy-saving tips.

# 5\. The system must provide the report for download.

#   
# \## ⚙️ Non-Functional Requirements

# 1\. The system must be developed using \*\*Java + Spring Boot\*\* (backend) and \*\*React\*\* (frontend).

# 2\. The system must be responsive and accessible on mobile devices.

# 3\. The system must include unit tests (JUnit/Mockito) and integration/end-to-end tests (Robot Framework).

# 4\. The system must be containerized with Docker for deployment.

# 5\. The system must ensure basic security (input validation and error handling).
