# Project Scope – Understand Your Electricity Bill

## 🎯 Objective
Develop a web and mobile application that allows users to understand the charges in their electricity bills, validating calculations based on ANEEL official tariffs and providing energy-saving suggestions.

## 📌 Core Features (MVP)
- Input form for bill data.
- Integration with ANEEL API.
- Processing and validation of charges.
- PDF report generation.
- Report download by the user.

## 🔮 Future Features
- User report history.
- Login and authentication.
- Comparative charts.
- Notifications about tariff flags.
- Mobile version (React Native).
